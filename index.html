YouTube Analytics · Aquarismo

Script em Python que coleta as métricas de um canal pela YouTube Data API e gera um relatório HTML e uma planilha CSV, com engajamento por vídeo e comparação entre Shorts e vídeos longos.

  • Python
  • YouTube Data API v3
  • pytest
  • CSV
  • HTML
  • Problema: conferir as métricas do canal vídeo por vídeo no YouTube Studio tomava tempo e não mostrava padrões.
  • Solução: um comando busca os vídeos do canal (com paginação e requisições em lote), calcula a taxa de engajamento e gera o relatório.
  • Boas práticas: só a biblioteca padrão do Python, chave da API em variável de ambiente (nunca no código) e testes automatizados com a API simulada.

Resultado real · canal @LoiraAquarismo

50vídeos analisados
79 milviews no canal
1.250views no melhor vídeo
até 4,8%engajamento no formato novo
  • Descoberta: os vídeos com título descritivo e conteúdo educativo tiveram o maior alcance e engajamento de 2,5% a 4,8%. Os vídeos com mais views do estilo antigo, de títulos só com hashtags, ficavam entre 0,75% e 1,5%.
  • Descoberta: hashtags sem relação com o tema trazem um pouco mais de views, mas derrubam o engajamento.
  • Decisão: manter o formato educativo, postar com constância e medir de novo em 4 semanas.
# Windows (PowerShell)
$env:YOUTUBE_API_KEY="sua-chave"
python youtube_report.py --channel "@LoiraAquarismo" --max-videos 50
# gera output/relatorio.html e output/videos.csv
